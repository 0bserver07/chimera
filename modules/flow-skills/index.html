Flow Skills

chimera.skills.flow lets you define agent workflows as Mermaid flowcharts, parse them into executable decision trees, and walk an agent through them step-by-step. The Flow class is a standalone utility — it does not require deep framework integration.

Quick Start

Section titled “Quick Start”

Mermaid Syntax

Section titled “Mermaid Syntax”

Flow supports standard Mermaid flowchart syntax:

SyntaxNode kind
A([BEGIN])Begin (exactly one required)
Z([END])End (exactly one required)
B[Read code]Task (rectangle)
C{Has tests?}Decision (rhombus)
C -->|yes| DLabeled edge
B --> CPlain edge

Nodes with more than one outgoing edge are auto-detected as decision nodes. All decision edges must have labels, and labels must be unique per node. The end node must be reachable from the begin node.

Section titled “Core API”

Parsing

Section titled “Parsing”

Returns a Flow with nodes (dict of FlowNode), edges (list of FlowEdge), begin_id, and end_id.

Section titled “Generating prompts”

Skill Discovery (pi-mono)

Section titled “Skill Discovery (pi-mono)”

chimera.skills.discovery provides automatic skill discovery so the REPL and agent loops can load Flow skills from well-known locations without manual registration.

Discovery API

Section titled “Discovery API”
FunctionDescription
discover_skills(paths)Search paths for SKILL.md files and return a list of loaded Flow objects
default_search_paths()Return the default search path list: ~/.chimera/skills/, ./skills/, and any paths from CHIMERA_SKILL_PATH env var

Auto-discovery in the REPL

Section titled “Auto-discovery in the REPL”

When chimera code starts, it calls discover_skills(default_search_paths()) and registers all found skills. Type /skills in the REPL to list them.
