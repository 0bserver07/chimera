Shrew Quickstart

chimera shrew Quickstart

Section titled “chimera shrew Quickstart”

chimera shrew is the fifth Chimera coding-agent CLI and the first one tuned explicitly for small local models. Where chimera mink mirrors a TUI-first agent, chimera otter mirrors a server-first multi-client agent, and chimera ferret mirrors an IDE-first sandboxed agent, shrew mirrors a small-model coding agent — a thin layer on top of chimera weasel that pins three small-model defaults, ships a curated skill set, and adds a benchmark harness for Aider Polyglot and GAIA.

The headline thesis: most “the model can’t code” complaints are really “the scaffold is too rich for this model”. Shrew exists to make a 9B–35B parameter local model feel like a competent coding collaborator by tightening the harness around it.

This page walks you from zero to a working session in five minutes. For deeper dives:

  • small-model-setup.md — llama.cpp build, GGUF download, MoE serving incantations.
  • skills.md — what the bundled skill markdown set is and how to extend it.
  • extensions.md — moe_offload, scaffold_fit, and tool_filter — the three small-model adjustments shrew layers on top of weasel.
  • benchmarks.md — Aider Polyglot + GAIA setup and evaluation.
  • parity-matrix.md — surface-by-surface parity status against the upstream small-model coding agent.
  • security-and-trademarks.md — trademark hygiene policy and the security posture.

Prerequisites

Section titled “Prerequisites”
  • Python 3.11+
  • uv
  • One of:
    • A running llama.cpp HTTP server on 127.0.0.1:8888 (recommended; see small-model-setup.md).
    • A running Ollama daemon on localhost:11434.
    • A cloud provider key (ANTHROPIC_API_KEY, OPENAI_API_KEY, or OPENROUTER_API_KEY) — used as a fallback when no local server is reachable.

Cloud SDK extras (--extra anthropic / --extra openai) are only required when you intend to fall back to a hosted model.

Provider configuration

Section titled “Provider configuration”

Shrew inverts the priority order weasel uses. A reachable local server is the default; cloud providers are the fallback. The full chain (first match wins):

  1. --model <id> on the CLI.
  2. $SHREW_MODEL environment variable.
  3. llama.cpp at $LLAMACPP_BASE_URL (default http://127.0.0.1:8888/v1) — probed via /health then /v1/models. Default model: qwen3.6-35b-a3b.
  4. Ollama at $OLLAMA_BASE_URL (default http://localhost:11434) — probed via /api/tags. Default model: qwen3.5:cloud.
  5. $ANTHROPIC_API_KEY set → defaults to claude-sonnet-4-6.
  6. $OPENAI_API_KEY set → defaults to gpt-4o.
  7. $OPENROUTER_API_KEY set → defaults to openai/gpt-4o.
  8. Friendly error pointing at every supported source.

The local-first ordering is deliberate: shrew exists to prove that small local models are good enough for real coding work; reaching for a cloud key should be a last resort, not the default.

The three flags that matter most

Section titled “The three flags that matter most”

Shrew inherits weasel’s full flag surface, but three flags are disproportionately useful for small-model work:

--model

Section titled “--model”

Pin the model identifier. Shrew’s default is qwen3.6-35b-a3b (a Qwen MoE checkpoint served by llama.cpp). Override examples:

For the full list of recognised local ids, run chimera shrew --list-models.

--vram-gb

Section titled “--vram-gb”

Tell shrew how much GPU VRAM you have. Shrew uses this to pick a safe context window via the moe_offload extension. Default: 8 (the laptop-class target). Bigger values unlock larger context windows; the helper snaps to a power of two and clamps at the model’s architectural maximum.

You can also set it via $SHREW_VRAM_GB so CI and one-shot scripts inherit the budget.

--no-skills

Section titled “--no-skills”

Skip the bundled skill set. Skills layer in extra system-prompt context (the curated knowledge / protocols / tools markdowns under chimera/shrew/skills/). They help small models a lot, but they do cost tokens. When you’re benchmarking or running a frontier model that doesn’t need the scaffolding, drop them:

The skill set is documented in skills.md.

Other useful flags

Section titled “Other useful flags”

The defaults shrew pins on top of weasel:

FlagShrew defaultWhy
--modelqwen3.6-35b-a3bLocal MoE, runs on a 32-64 GB Mac at 4-bit quant.
--max-steps30Smaller than mink/otter’s 50 — small models loop on long horizons.
--allowed-toolsRead,Write,Edit,BashMinimal high-leverage toolkit; small models choke on big tool menus.
