# Chimera 0.9.0 — the TUI multiplexer: race N agents on one task

**Released:** 2026-07-01

Chimera exists for controlled comparison of coding agents. 0.9.0 turns that
mission into a live terminal interface: **N agent lanes race one task,
side-by-side, in isolated workspaces** — and you watch cost, tokens, steps,
time, and the actual produced code diverge in real time. None of the reference
terminal agents multiplex; this is the differentiator. Everything below was
verified live against GLM-5.2 (and GLM-4.6 for the races).

```bash
pip install 'chimera-run[tui,anthropic]'
chimera code --tui --models glm-5.2,glm-4.6          # two models, one task
chimera code --tui --models glm-5.2,glm-5.2:coding_agent:plan-execute
#                            default ReAct vs a genuinely different reasoning loop
```

## The multiplexer

`chimera code --tui --models a,b,c` (or `chimera otter --multiplex a,b,c`)
launches N concurrent lanes, each with **its own git worktree** (copy fallback
for non-git projects) so file-writing agents never share a mutable tree. A
broadcast prompt starts the race; targeted mode (`Ctrl+B`) steers one lane.
The global bar tracks done *k/N*, Σcost, elapsed, and first-to-finish; panes
degrade to tabs on narrow terminals. Each run persists a self-contained
comparison artifact under `~/.chimera/cohorts/<id>/` — manifest, ranked
summary, and per-lane transcripts + diffs (`--export` zips it).

## Compare, resume, vary the agent — not just the model

- **In-UI comparison view** (`Ctrl+R`): a ranked scoreboard over a per-lane
  diff viewer — navigate files (`n`/`p`), toggle a side-by-side split view
  (`s`). Lane diffs exclude the agent's own `.chimera/` bookkeeping.
- **Resumable cohorts**: `--list-cohorts` then `--tui --resume <id>` — lanes
  are rebuilt from the recorded base commit with their saved diff re-applied
  and a faithful history replay (tool calls preserved), and the race continues.
- **Heterogeneous lanes**: the lane spec is `model[:preset[:loop]]`. Vary the
  preset (tool set + prompt), a loop *posture* (`plan`, `tdd`), or swap in a
  **genuinely different reasoning loop** — `plan-execute`, `reflexion`, `tot` —
  via the new loop adapter, which bridges the strategy loops into the TUI's
  event stream on a worker thread so lanes stay concurrent.

## Reasoning, rendered — and nicer transcripts

Extended-thinking deltas now flow end-to-end (the provider stream mapper was
silently dropping them): they arrive as `thinking_chunk` events and render as
dim, **collapsed-by-default** blocks — `Ctrl+E` shows them. GLM-5.2 via z.ai
surfaces real thinking with `enable_thinking=True`. Assistant prose renders as
**markdown** (styled headers, bullets, syntax-highlighted code fences), while
tool output and file contents stay literal. The prompt is multi-line
(`Ctrl+J` newline, history recall) with slash autocomplete, and `Ctrl+T` opens
a per-lane tool-call sidebar.
