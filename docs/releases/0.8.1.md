# Chimera 0.8.1 — `chimera code` becomes a real daily driver

**Released:** 2026-06-30

0.8.0 shipped the comparative-methodology mission. 0.8.1 turns the other
surface — `chimera code`, the interactive coding agent — into something you can
actually daily-drive. Every change below was verified live against GLM-5.2.

## A driver API, and a rebuilt REPL on top of it

The coding agent is event-driven: the agent emits a typed event stream and the
UI renders it. The new `AgentDriver` (`chimera/assembly/driver.py`) is the one
object a REPL or TUI drives:

- `send(text)` streams `LoopEvent`s for a turn;
- `steer()` / `queue_follow_up()` inject messages mid- or post-turn;
- `cancel()` / `clear()` abort or reset;
- and it exposes the model, tools, cumulative cost, history, and context window.

`chimera code`'s REPL is now a thin client over that driver: streaming output
with tool calls rendered *before* their results, conversation memory across
turns, per-turn cost, and real slash commands. The full contract is documented
in `docs/building-a-tui.md`.

## Unlimited runs, made safe

`chimera code --max-turns 0` (or `max_turns=None`) runs until the task is
actually done. Two things make that trustworthy:

- **Compaction tracks the real context window.** A 1M-token model
  (`glm-5.2[1m]`) is no longer compacted at a fixed 100K — it uses the whole
  window.
- **A loop detector** stops a stuck agent (repeated identical tool calls) with
  reason `loop_detected` instead of spinning.

## Zero-config credentials

`chimera code` now loads a project `.env` and `~/.config/chimera/env` at
startup — existing shell variables always win — so provider creds and model
selection work without exporting anything. Keep provider keys out of your global
shell (so they don't hijack other tools that read the same variables) and let
chimera load its own.

## Provider fixes for GLM

- The `[1m]` suffix (`glm-5.2[1m]`) is stripped from the wire id — which z.ai
  rejects — and used as the context-window declaration.
- Default `max_tokens` is model-aware: GLM / Kimi / Qwen get 32768, Claude 8192
  (was 4096), so long edits aren't truncated.

## Correctness

- `--workdir` now applies to every tool (file, shell, `test`,
  `replace_in_file`, `apply_patch`), not just the ops-based ones.
- The `coding_agent` system prompt is sharper and more action-first.

Full details are in `CHANGELOG.md`.
