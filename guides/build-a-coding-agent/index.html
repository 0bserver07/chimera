Build a Coding Agent

This guide walks you through building an interactive coding agent from scratch. By the end you will have an agent that reads files, runs shell commands, holds multi-turn conversations, detects loops, and respects permission guardrails.

1. Setup

Section titled “1. Setup”

Install chimera and export your API key:

Create a provider — the bridge between your agent and the language model:

create_provider infers the backend from the model name. The model parameter is optional — when omitted, it falls back to the ANTHROPIC_MODEL environment variable. You can also pass provider_type explicitly (e.g. "openai", "google", "ollama").

2. Basic Agent

Section titled “2. Basic Agent”

An Agent wires together four things: a provider, a list of tools, a loop (reasoning strategy), and a prompt.

DEFAULT_TOOLS is a ToolGroup containing ReadFileTool, WriteFileTool, BashTool, and ImageReadTool. For interactive sessions with more tools (edit, search, git, think, todo, etc.), use AGENT_TOOLS instead — a 13-tool preset that the REPL uses by default. Pass env=None when you do not need a managed workspace, or supply a LocalEnvironment("./workspace") for sandboxed file access.
