# Chimera 0.9.2.1 — the verified grader

**Released:** 2026-07-27

A sub-version, deliberately — the third digit is not a batch counter
(`docs/playbooks/14-release-discipline.md`, rule 0).

The theme is uncomfortable: **the things that check our work were not
checking it.** A benchmark adapter can be completely broken while its unit
tests are green, because those tests assert the adapter *runs*, never that a
correct answer *scores*. A pricing auditor can report clean while the number
that actually bills lives in a different table. This release closes both gaps,
and retracts a published figure that did not survive the closing.

```bash
pip install 'chimera-run[tui,anthropic]'
```

## The canary — grade the grader

Take a task's **own canonical solution**, hand it to `evaluate()` the way an
agent would, and require a pass. If a dataset's own reference answer cannot
score, nothing an agent writes will either, and every number that adapter ever
produced is fiction.

```bash
python scripts/canary_benchmarks.py             # every staged adapter
python scripts/canary_benchmarks.py --limit 200 # full-dataset sweep
```

First full sweep: **7 pass, 0 broken, 1 not staged, 19 exempt.** The seven
include every adapter behind the published flagship scorecard, so those numbers
now rest on a verified grader.

Two rules make it trustworthy:

- **The inverse is checked.** A grader hardwired to return `True` would sail
  through a positive-only canary with a perfect score, so every adapter is also
  fed wrong, empty and prose-only answers and must reject all three. *A canary
  that cannot fail is not a canary.*
- **Answers go in the shapes agents actually send** — dataset-native, fenced,
  and fenced-wrapped-in-prose. The HumanEval-X fabricated zero hid for a whole
  release precisely because the old tests only fed the first shape, the one an
  instructed chat agent never produces.

`ENV-MISSING` and `NOT-STAGED` are reported rather than skipped, so an
unaudited adapter stays visible instead of being mistaken for a healthy one.
**The 19 exempt adapters are unverified, not healthy.** Guide:
`docs/guides/benchmark-canary.md`.

## A retraction

The published **LiveCodeBench ≥18.9% (33/175) is withdrawn**, from the
observatory, the progress matrix, the Modal bench page and the v0.9.1 release
notes.

It shipped as a "documented lower bound". A lower bound is still a claim — *at
least this good* — and it is only honest when the unmeasured remainder **could**
have passed. 63 of the 175 staged tasks are `functional` + `starter_code` while
the runner executed `python solution.py < stdin`, so **36% of the denominator
could not pass under any answer**. A floor over a 36%-unpassable denominator is
not conservative; it is a fabricated number with an inequality in front of it.

Two of the three underlying defects are now fixed — functional tasks are graded
by *calling* the `Solution` method, and `--limit` is stratified across platforms
(`--limit 50` is now 25 AtCoder + 25 LeetCode, was 50 + 0). The third is not,
and is disqualifying alone: **only public sample tests are staged**, and for 24
of 50 tasks in one slice every graded assertion is printed in the prompt.

The retraction is not a one-off edit. `RETRACTED` in
`scripts/render_observatory.py` is a registry: a retracted adapter renders the
withdrawal plus its full reason instead of *any* score, is dropped from the
page's reproduce commands, and has its n=1 ticks annotated. **A future run
cannot republish the number.**

The v0.9.1 release note is struck through with a dated correction rather than
rewritten — a release note is a historical record, and silently editing a
published number is the same class of dishonesty as publishing a wrong one.

## Pricing — and why fixing the table would not have fixed it

DeepSeek was billed at up to **3.9x** its published rate. Three compounding
defects, and the first one alone would have defeated a naive correction:

1. **There are two pricing tables.** `chimera/providers/catalog.py` carries its
   own `cost=` per model, and registering a catalog pushes it through
   `register_model_cost`, which **writes into `PRICING` at runtime**. Correcting
   `cost.py` alone was silently reinstated the moment a catalog was built — the
   same process returned the right rate before a catalog existed and the wrong
   one after, which is why it only failed in a full-suite run.
2. **"First-party" is not a property of a provider.** models.dev lists a model
   under every provider that serves it; `alibaba-cn` manufactures Qwen but
   merely *resells* GLM. With a provider-global authority test the auditor
   reported `glm-5.2` as drift and instructed replacing Zhipu's $2.00/$8.00 with
   Alibaba's $1.10/$3.851 — a confidently wrong "correction" to the headline
   model. Authority is now a (model family → vendor) relationship.
3. **A placeholder override could never expire.** "Pending the vendor's rate
   sheet" stayed silent after the vendor published. `PRICING_PLACEHOLDERS` now
   expires them and fails **even when the rates agree**, because the finding is
   the expired reason, not the number.

No published benchmark figure used DeepSeek, so no result is affected.

## `list_files` was unbounded

A single `list_files(".")` in a repo with a `.venv` or `node_modules` returned
the whole tree as one tool result — millions of tokens — busting the model's
prompt limit and stalling the agent loop after its first tool call. It now skips
26 vendored/generated directories when listing a parent and caps output at 1000
entries with a truncation note. An explicit `path` **into** an ignored directory
still lists it, so nothing is truly hidden.

Two more loop fixes land with it: the agent loop **dropped the final answer** on
the no-tool-calls path (rendered live, written to the transcript, never appended
to history — invisible to save/resume), and **TUI resume rendered a blank pane**
because it seeded the driver context without replaying the conversation.

## Environments — Daytona, E2B, and SSH proven

`DaytonaEnvironment` joins Modal and E2B behind the same `Environment` ABC, and
E2B — previously reachable only from Python — is now CLI-selectable. Both
**refuse to construct without credentials** rather than silently degrading to
local execution, because a sandbox that quietly ran locally would produce
benchmark cells indistinguishable from real cloud ones.

`AsyncSSHEnvironment` turned out to be already built; what was missing was
proof. All 12 of its tests sat behind `pytest.importorskip('asyncssh')` — CI's
exact posture — so none of them ever guarded a merge. 34 contract tests now
drive the real class against a fake injected at the module boundary, and they
found a real defect: `asyncio` was imported inside the same `try:` as
`asyncssh`, so a missing extra set the stdlib module to `None`.

## Also in this release

- **A cross-backend integrity fix**: `list_files` used `fnmatch`, whose `*`
  crosses `/`, so the same benchmark saw different files depending on the
  sandbox. One shared `glob_match`, pinned by parity against a live
  `LocalEnvironment`.
- **HumanEval-X's fabricated zero** — a live grid scored `0/50` with
  `{completed: 50}` because the grader executed prose as Python. The same 50
  tasks re-run at **50/50**.
- **A disclosed ceiling**: `humaneval-plus`/`HumanEval/32` is unpassable by
  construction (an upstream EvalPlus assertion splats a float), capping that
  column at **163/164 = 99.4%** — now published *with* the score.
- **TUI phase-3 polish**: semantic slot themes, per-tool renderers, word-level
  diffs, a `Ctrl+F` transcript overlay, paste chips, and OSC-133 zone marks.
- **Inline mode**: 4 of 9 manual checklist steps now pass with evidence on
  Terminal.app, including full DECSTBM scroll-region release on exit. Selection,
  scroll, resize and Ctrl+C-cancel remain untested, so **the default stays off**.

## Gates

Full suite **10,416 passed / 98 skipped / 0 failed** (excluding the three
documented live-infra files). CI-posture suite **9,954 passed** — CI installs no
`tui` extra, so that gate is run separately. `ruff` clean, `mypy` clean across
724 source files, all 7 trademark scrubs pass.

No breaking changes. If you have cited a LiveCodeBench figure from Chimera,
