# Chimera 0.9.1 — the honest harness

**Released:** 2026-07-11

A patch release, deliberately: 0.9.x continues (see
`docs/playbooks/14-release-discipline.md`). The batch has one theme —
**numbers you can trust, on infrastructure that stays up, behind a terminal
that earns daily use.** Everything below is live-verified: the scorecards
carry per-task `status_counts`, the endpoint smoke ran against a real
deployment, and the TUI smoke drove a real coding turn on GLM-5.2.

```bash
pip install 'chimera-run[tui,anthropic]'
chimera code --tui                      # the daily driver (one-lane multiplexer)
chimera bench-matrix --agents coding-agent --benchmarks mbpp --limit 5
```

## Measurement integrity — the war, won

The wide grids exposed harness bugs that inflated results; every one is fixed,
regression-tested, and enforced by `scripts/verify_status.py`:

- Errored/empty agent runs can no longer grade as passes — including a
  HumanEval+ checker that was never invoked (all pre-fix HumanEval+ numbers
  were invalidated and re-measured).
- Faithful SWE grading: the official `FAIL_TO_PASS` / `PASS_TO_PASS` node ids
  for swe-bench, swe-polybench, and multi-swe-bench, with a vacuous-pass guard
  (zero-test pytest runs don't count).
- Cells report `status_counts` (exact failure-vs-error split), aggregate ALL
  task attempts, preserve real cost on mid-run errors, and budget tracking
  covers async + streaming provider paths.

The payoff — the flagship `coding-agent` full-dataset scorecard on glm-5.2,
EXACT (zero infra errors) unless noted: **mbpp-plus 99.7% · mbpp 99.1% ·
human-eval-plus 92.1% · math500 77.6%** · livecodebench ≥18.9% (documented
lower bound). Runnable set: 16 benchmarks / 7,064 tasks.

## Benches on Modal, endpoints on Modal

- **The grid runs in the cloud**: per-task Modal/GPU sandboxes
  (`--env modal`), whole cells with orchestration + inference + grading all
  cloud-side, parallel fan-out, and **durable detached grids** that persist
  every cell to a Volume — a sleeping laptop can't lose a run. SWE instances
  run in their official per-instance images (`--env swe-modal`).
- **Modal managed Endpoints as a provider**: `modal-endpoint/<hf-repo-id>`
  model strings, proxy-token header auth, endpoint discovery. Live-smoked
  against a real GLM-5.2-FP8 endpoint on 8×B200 (exact-match reply, 1.16 s
  warm, 40.5 tok/s) — see `docs/guides/use-modal-endpoints.md` for the
  fully-cloud loop and the cold-start field notes.

## The TUI grows up

Bare `chimera code --tui` is now the **one-lane multiplexer** — the full
surface (results, resume, `/cohorts`) with single-lane chrome. On top of it,
mined from a six-reference corpus and spec'd in
`docs/specs/tui-ux-refinements.md`:

- **Stream-safe rendering**: completed markdown blocks commit while streaming
  (never half-parsed), nested fences normalized, and a **live-tail region**
  shows the in-progress remainder plus a reasoning heartbeat
  (`∴ Thinking ··· 5s · ~1.2k chars · 240 chars/s` — honest chars, not fake
  tokens).
- **Follow-mode scrolling**: pinned to the tail only while you're at it;
  scroll up and it freezes; drag-select is never fought.
- **Registries own the chrome**: rebind keys via `tui.keybinds` (validated,
  conflict-checked, `/keys` shows the table), compose the status line via
  `tui.status_line` (real provider-reported context usage, threshold-colored,
  async git facts), `/help` renders the *currently bound* keys.
- **Approval modals (opt-in)**: `CHIMERA_TUI_APPROVALS=1` gates risky tool
  calls behind lane-named Allow / Allow-for-session / Deny-with-feedback
  modals, FIFO-queued, deadlock-guarded. Defaults unchanged.
- Tool output is head+tail elided on screen (Ctrl+X expands) while the session
  record keeps everything — the old behavior silently capped *persisted*
  transcripts at 1,500 chars.

User guide: `docs/guides/tui.md`. Exploratory next step already spiked with a
GO: a native-scrollback hybrid transcript (`docs/specs/tui-scrollback-hybrid.md`).
