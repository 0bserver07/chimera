# Chimera 0.8.0 — The Comparative-Methodology Release

**Released:** 2026-06-11

Chimera's mission has three pillars: replicate agent architectures,
control the variables, and unify the benchmark interface. 0.7.0 shipped
the replicas. **0.8.0 ships the other two pillars** — and the first
artifact that uses all three at once.

## The headline: `chimera bench-compare`

One command produces the controlled comparative matrix: same model,
same tools, same per-task budget, with the agent loop as the only
variable.

```bash
chimera bench-compare \
    --agents react,plan-execute,reflexion,tree-of-thought \
    --benchmark harbor --dataset /path/to/deep-swe/tasks --limit 10 \
    --model glm-5.1 --max-tool-calls 30 --max-wall-clock 600 \
    --seed 0 --format html --output matrix.html --emit-atif trajectories
```

The "controlled" claim is load-bearing, so it is enforced and audited
rather than asserted:

- **Budgets are uniform by construction.** The universal unit is
  *completed tool calls*, recorded once at the shared tool executor —
  the one choke point every loop already routes through. Exhaustion
  trips the run's cancellation token, so every loop stops through its
  existing cooperative-cancel path. The audit test drives all four loop
  types with a scripted always-call-a-tool provider under a 3-call
  budget and asserts each stops at exactly 3.
- **Budget hits are not failures.** `CompareReport` carries
  `budget_hits` / `budget_reasons` as their own columns; a crash in one
  task is recorded as that task's failure and never kills the matrix.
- **Same seed, same pool, same budget → same matrix.**

### The first live matrix

Published in the repo at
`docs/benchmarks/2026-06-11-first-controlled-matrix.md`:
react vs plan-execute on GLM-5.1 over a 3-task self-asserting pool.
react solved 3/3 at $0.0009/task in one turn each; plan-execute solved
0/3 at ~16× the cost and exhausted its budget on every task. Small
pool, big signal: a planning loop is pure overhead on single-turn
tasks — exactly the kind of architectural fact the methodology exists
to surface, for about five cents.

## Harbor / DeepSWE

`--benchmark harbor` consumes any Harbor-format task directory with no
per-benchmark code — validated by parsing all 117 real DeepSWE tasks.
`docker_env_factory` provisions a task's prebuilt image (new `docker`
extra), and the verifier flow (apply `test.patch`, run `test.sh`) is
proven end-to-end inside a live container.

## ATIF v1.7 — trajectories that cross frameworks

`chimera/atif/` (stdlib-only) emits, reads, and validates ATIF v1.7
trajectories. The emitter subscribes to a run's event bus and writes
one step per API turn with the model's verbatim text — never
fabricated — plus per-turn token metrics and the augmented aggregates
(`peak_context_tokens`, `summarization_count`) where Pier puts them.
Interop is proven, not claimed: the test suite validates
Chimera-emitted trajectories with **Pier's own pydantic models**.
`bench-compare --emit-atif DIR` writes one trajectory per (agent,
task) and records the paths in the report.

## Field Guide

[Eleven pages](https://0bserver07.github.io/chimera/field-guide/)
cataloging the architecture of every agent Chimera replicates — loop,
tool set, edit format, context strategy, termination — written from
firsthand reading of the upstream sources and the replicas, with a
sortable cross-agent taxonomy. No benchmark scores by design; the
matrix carries those.

## Teams: plan approval

Tasks created with `requires_plan` cannot complete until a lead
approves the claiming agent's proposed plan — `team_propose_plan` /
`team_approve_plan` MCP tools (approve is lead-gated), an interactive
`chimera team approvals` loop, and `CHIMERA_AUTO_APPROVE_PLANS=1` for
headless runs. The teammate runner also stops claim/release spinning:
dep-blocked tasks no longer cue agents, no-progress spawns always
sleep, and a force-released task is reconsidered the moment its record
materially changes (e.g. the lead approves).

## Live-run honesty

Running things, not just building them, drove this release's fixes:
the first matrix run exposed a harness-killing crash path and an
ATIF fidelity collapse (both fixed with tests); the first-ever
ProgramBench instance run (#141) exposed four divergences between the
adapter's assumptions and the real cleanroom images (extraction path,
layout, macOS path resolution, prompt guidance) — all fixed, with the
harness now validated end-to-end and agent convergence tracked as the
open follow-up. The Opus 4.5+ pricing in the cost catalog was also
corrected to the current public $5/$25 per MTok.
