# Chimera 0.9.2 — the embeddable core

**Released:** 2026-07-24

A patch release, deliberately (0.9.x continues — see
`docs/playbooks/14-release-discipline.md`). The theme is turning capability
Chimera already had into capability *other people can use*: three claims, each
self-demonstrating.

```bash
pip install 'chimera-run[tui,anthropic]'
```

## Embed me — the SDK cut

One documented, semver-stable surface, exported from the package root:

```python
import chimera

with chimera.AgentSession(model="glm-5.2", project_dir="./myrepo") as agent:
    result = agent.run("add a --verbose flag to the CLI and a test for it")
    print(result.text, result.cost_usd, result.steps)

# or the one-liner
chimera.run_agent("fix the failing test", model="glm-5.2")
```

`AgentSession` streams typed events (`send`), steers mid-turn, cancels, swaps
models, and reports cost/history; `TurnResult` carries text, cost, steps,
reason, duration, usage. Guide: `docs/guides/embed.md` — verified by running
its copy-paste script from outside the repo against a real model.

## Verify me — the observatory

`docs/benchmarks/observatory.md` is generated entirely from committed
`data/*.json` receipts by `scripts/render_observatory.py`. Every number names
its source file; every section carries a `uvx` one-liner that re-runs it. The
generator **aborts the build** if a receipt violates measurement integrity
(an `error`-status cell claiming passes), and `--check` fails when the
committed page drifts from the data.

It ships with the first real multi-agent **depth matrix** — 4 architectures ×
4 benchmarks at n=50 on glm-5.2 ($4.34, `observatory1`): mbpp and mbpp-plus
saturate near 100% across architectures while math500 separates them 80–84%.
Errored cells render as `error` with their cause (never as a 0% *score*), and
a requested-but-absent agent is named in an explicit "Incomplete run" block —
a partial grid can never present as a complete one.

## Race them — external-agent lanes (#169)

Third-party agent CLIs now run as multiplexer lanes beside Chimera's own
agents, on the same task, in isolated worktrees:

```bash
chimera code --tui --models ext:claude,glm-5.2
```

`ExternalAgentDriver` speaks two protocols (newline-JSON events, or plain
text with honest zero-telemetry and a note), gets per-lane worktree isolation
so its diffs land in the comparison screen, cancels cooperatively (SIGTERM
with grace, never a first-strike kill), and persists + resumes with the
cohort. Live-proven: an external lane and the flagship both solved one task —
$0.3265 / 5 steps versus $0.0028 / 3 steps, measured by one harness.
Guide: `docs/guides/external-lanes.md`.

## The framework underneath

- **Provider capability matrix** — quirks are now *data* keyed by wire
  protocol (openai-compat / anthropic-compat / google), with protocol →
  provider → model-prefix resolution. `CompatFlags` became its openai-compat
  projection; hardcoded prefix tuples became rows. **A new backend on an
  existing protocol is a ~20-line data row** (proven by a fictional provider
  in the tests). Guide: `docs/guides/add-a-provider.md`.
- **Interception seams** — typed, decision-capable hooks in `LoopConfig` that
  **block, mutate, and rewrite** (not just observe) at four load-bearing
  points: the provider request (payload + headers), a tool call before
  execution, a tool result before it enters context, and the outgoing message
  list. Tool interception runs *before* the permission check, so policy always
  sees the effective arguments. Guide: `docs/guides/interception.md`.
- **Hermetic loop harness** — `chimera.testing` runs scripted turns through
  the **real** loop with real tools in a temp workspace: ordered events, file
  diffs, usage/cost, mid-stream steering and cancel, error injection. Ships
  with regression locks named for the commits they guard (each revert-verified
  against the actual pre-fix code). It complements — never replaces —
  real-LLM validation. Guide: `docs/guides/testing-agents.md`.
- **One config chain** (#173) — the TUI's two config dialects collapse into a
  single loader: canonical `~/.chimera/config.toml`, YAML/JSON kept as a
  read-time compatibility shim, one precedence chain (XDG < user < project).
  Keybindings, status line, skills, and cohort retention all read it.
- **Lane and cohort budgets** (#170) — cost / steps / wall-clock caps per lane
  and across a cohort, with honest terminal reasons
  (`budget_exhausted:cost`, `cohort_budget:wall_clock`), a threshold-colored
  status-line meter, and manifest persistence. Set them five ways: CLI flag,
  a 4th `--models` field, config, `/budget`, or a kwarg.
- **Opt-in inline mode** — the single-agent daily driver can render into the
  terminal's **native scrollback** (composer pinned below), so selection,
  copy, and wheel-scroll work natively and the transcript survives exit.
  POSIX TTYs only, with a capability gate that falls back to full-screen
  (including on a terminal multiplexer that drops partial-region scrollback).
  **Default off**, pending the manual checklist in `docs/guides/inline-mode.md`.
- **TUI selection & copy** — `Ctrl+Y` copies the transcript selection over
  OSC 52 (works across SSH), and `--no-mouse` hands the mouse back to the
  terminal for native click-drag selection.
- **Cross-harness skill interop** — discovery can read other harnesses' skill
  directories, default off, provenance-labeled so foreign skills are visibly
  third-party. Precedence: project > user > foreign.
- **Cohort auto-pruning** — `[tui.cohorts] retain` / `max-age-days` caps what
  the daily driver accumulates. Off by default; never prunes the live cohort.

## Fixed

- **Generic session-entry payloads survived nothing** — extension/custom state
  attached to a session entry was silently dropped on serialize, so it never
  came back after a reload. Found by a verify-first audit that also *pinned*
  two properties that already held: compaction is append-only reversible (you
  can branch back to before it) and re-compaction merges the prior summary
  rather than re-summarizing.
- **Stale hand pricing is now detectable** — a dev-only reconciler audits the
  hand-maintained pricing table against upstream, with an explicit override
  marker for deliberate divergence. It immediately caught real drift in the
  DeepSeek rates.
- **Shell-history isolation** — spawned tmux session shells no longer write
  into the user's real shell history (a truncation hazard), with quote-armored
  sentinels and pane-wrap-safe capture.
